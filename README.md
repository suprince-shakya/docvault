# 📁 DocVault - Next.js Document Vault System

A secure and scalable document vault system built with **Next.js**, **TypeScript**, and modern backend technologies. Easily upload, organize, and manage your documents with access control.

## 🚀 Features

- 🔐 User Authentication (JWT / OAuth)
- 📤 File Upload & Download
- 🔍 Full-text Search
- 🧾 Share file to users
- ☁️ Cloud Storage Support (local disk)

---

## 🧱 Tech Stack

- **Frontend**: Next.js + Tailwind CSS + TypeScript
- **Backend API**: Next.js API routes / REST
- **Database**:  MongoDB
- **File Storage**: Local disk via Multer
- **Auth**: NextAuth.js / JWT
- **State Management**: React query

---

## 📦 Installation

```bash
git clone https://github.com/suprince-shakya/docvault.git
cd docvault
or npm install / yarn install
npm run dev
```
